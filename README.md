## git提交规范：
1. 自己创建一个branch写代码，命名格式为"名字缩写_dev",例如"Hn_dev"
2. 完成一个功能后先上传到自己的分支以保存
3. 合并功能由我实现，其他人只负责提交代码和合并请求
4. 代码合并后，每个人先将main分支的内容合并到自己分支，再进行开发
